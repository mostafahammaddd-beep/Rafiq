# Rafiq - رَفِيق

## ما الجديد في هذه النسخة
التطبيق صار يدعم **فحصاً دقيقاً على مستوى الفونيمات** (حروف + تشكيل + تجويد) عبر خادم مرفق في مجلد `server/`.
بدون عنوان خادم يعمل التطبيق بالوضع **التقريبي** القديم (تعرّف عام على الكلام) وهو لا يلتقط التشكيل ولا التجويد.

## الخطوات
1. شغّل الخادم: اتبع `server/README.md` (Hugging Face Space أو حاسوبك).
2. ارفع ملفات المشروع إلى مستودع GitHub (بما فيها `.github` و `app/debug.keystore`) وانتظر `Actions > Build APK`.
3. نزّل الـ APK من **Releases** أو من Artifacts > Rafiq-APK.
4. في شاشة البداية الصق عنوان الخادم في حقل «عنوان خادم الفحص الدقيق».

الملف `app/debug.keystore` يثبّت توقيع التطبيق فتُثبَّت كل نسخة جديدة فوق السابقة.
