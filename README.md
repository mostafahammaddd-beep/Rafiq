# Rafiq - رَفِيق (الإصدار الحادي عشر v11.0 — التدقيق الصوتي القرآني المباشر عبر Gemini Multimodal API)

## البنية التقنية الكاملة للإصدار الحادي عشر (v11.0)

### 1. الإدخال الصوتي المباشر متعدد الوسائط (Direct Multimodal Audio Ingestion)
- تم إزالة مكتبات تحويل الكلام إلى نص التقليدية (STT / `SpeechRecognizer`) من جهة العميل بالكامل، لأنها تطبّع التشكيل وتستبدل الكلمات الخاطئة تلقائياً.
- يلتقط `RawAudioRecorder` في `RemoteAuditor.kt` الصوت الخام مباشرةً من الميكروفون بتردد `16kHz` وعمق `16-bit Mono PCM`، ويغلّفه في ترويسة `WAV` قياسية خفيفة (`44-byte RIFF/WAVE header`) مع تشفير `Base64`.
- يُرسل الصوت الخام مباشرةً بجانب نص الآية الكريمة بالتشكيل الكامل وأحكام التجويد وفهرس الكلمات (`0..49`) إلى `Gemini API`.

### 2. إعدادات استدعاء Gemini API الصارمة
- ضبط `temperature: 0.0` لمنع التخمين أو الهلوسة الصوتية.
- فرض مخرجات JSON المهيكلة عبر ضبط `response_mime_type: "application/json"`.
- حقن التعليمات الصارمة للنظام (`GEMINI_SYSTEM_PROMPT`) التي تطبّق:
  1. الأصل في التلاوة الصحة ما لم يتجاوز اليقين بالخطأ الجلي أو الخفي الواضح `90%`.
  2. قاعدة الوقف بالسكون («العرب لا تقف على متحرك»).
  3. المرونة الطبيعية في مقادير المدود والغنة.
  4. التمييز بين اللهجات الصوتية الطبيعية وبين الأخطاء الحقيقية في الحروف أو التشكيل أو التجويد.

### 3. فلترة مستوى الثقة من جهة العميل (Client-side Confidence Filtering)
- قبل عرض أي خطأ في الواجهة، يقوم `GeminiRecitationAuditor.filterErrorsByConfidence` بفلترة المصفوفة `errors` واستبعاد أي خطأ يقل حقل `confidence` فيه عن `0.85`، ومعاملة الكلمة ككلمة صحيحة تماماً لحماية القارئ من الإنذارات الكاذبة.

### 4. واجهة المستخدم وحالات الاتصال والتلوين التفاعلي
- **فحص الاتصال بالإنترنت:** عند انقطاع الاتصال يعرض التطبيق التنبيه:
  `«عذراً، يتطلب التحليل الصوتي المتقدم للتجويد والتشكيل اتصالاً بالإنترنت»` مع إبقاء القراءة القرآنية ومراجعة أحكام التجويد متاحة دون إنترنت.
- **حالة التحميل:** أثناء معالجة الصوت يعرض التطبيق مؤشر تحميل أنيقاً مع النص:
  `«جاري الاستماع والتدقيق التجويدي والتشكيلي...»` ويُعطّل زر التسجيل لحين اكتمال الطلب.
- **تلوين الكلمات القرآنية:**
  - **الأحمر (`Red`):** خطأ في الحروف أو الكلمة (`Letter`).
  - **الأصفر (`Yellow`):** خطأ في التشكيل والحركات (`Tashkeel`).
  - **البرتقالي (`Orange`):** خطأ في التجويد أو المدود أو الغنة (`Tajweed`).
  - **الأخضر (`Green`):** تلاوة متقنة وصحيحة.
- **التغذية الراجعة التفاعلية:** عند الضغط على أي كلمة خاطئة تظهر بطاقة تفصيلية تعرض النطق الصحيح المتوقع (`expected`) مقابل ما تم نطقه (`detected`) ونصيحة التصحيح بالعربية (`correction_tip`).

### 5. نافذة الإعدادات وتخزين مفتاح Gemini API محلياً
- تتضمن الواجهة نافذة إعدادات (`⚙️ إعدادات Gemini API`) تتيح للمستخدم إدخال وحفظ `Gemini API Key` محلياً في `SharedPreferences` على الجهاز، مع رابط مباشر إلى **Google AI Studio** (`https://aistudio.google.com/`) للحصول على مفتاح مجاني.
