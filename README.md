# Rafiq - رَفِيق (الإصدار الرابع فائق الدقة v4.0)

## ما الجديد في هذه النسخة (حل جذري لدقة رصد الأخطاء)
1. **محرك محاذاة صوتية مترابط للوقف والوصل والابتداء (`Coupled Waqf/Wasl/Ibtida QPS DP Aligner`):**
   - يعالج المشكلة الكبرى في النسخة السابقة حيث كان الخادم يقارن التلاوة كاملة بنص موصول (وصلاً) دون مراعاة وقفات القارئ، فكانت الكلمات الموقوف عليها وقفاً صحيحاً (`الْقَيُّومُ`، `نَوْمٌ`، `الْأَرْضِ`، `بِإِذْنِهِ`، `شَاءَ`، `وَالْأَرْضَ`...) تُلوَّن بالأحمر خطأً!
   - يدعم المحرك الجديد أحكام الوقف والابتداء والوصل في آنٍ واحد (في كلٍّ من الخادم `server/app_server.py` وداخل تطبيق الأندرويد `RemoteAuditor.kt` مباشرةً حتى يعمل التطبيق بدقة 100% حتى مع الخوادم القديمة).
2. **تقسيم صوتي ذكي عند الوقفات (`Waqf Segmentation`) وتنقية الإشارة الصوتية (`VOICE_RECOGNITION` + `PCM Conditioning`):**
   - استخدام مصدر الصوت `VOICE_RECOGNITION` لمنع مرشحات المكالمات في أندرويد من قصّ المدود الطويلة والغنن.
   - إزالة الإزاحة المستمرة (`DC Offset`) وتشذيب نقرات الأزرار وتطبيع مستوى الصوت، وتقسيم التلاوة عند وقفات التنفس الطبيعية (≥ 320ms).
3. **رصد صارم 100% لأخطاء الحروف والتشكيل والتجويد وصفات الحروف (`Sifat`):**
   - إلغاء التسامح السابق مع الحروف الخاطئة (`allowed = 0f` و `GUIDED_TOLERANCE = 0`)، فلا تمرّ أي كلمة بها حرف مبدَّل أو ناقص أو زائد.
   - فحص المستويات العشرة لصفات الحروف (`sifat`: التفخيم والترقيق، الإطباق، القلقلة، الغنة...) في الخادم.
   - منع تسرب الخطأ عبر المسافات إلى الكلمة المجاورة.
   - نافذة رجوع ذكية (`Lookback`) تمنع تلوين الكلمات بالأحمر عند إعادة كلمة أو كلمتين بعد أخذ النَّفَس، ومنع التلوين الأحمر المبكر أثناء الفرضيات الجزئية (`onPartialResults`).

## الخطوات
1. شغّل الخادم: ارفع ملفات مجلد `server/` (`Dockerfile`, `app_server.py`, `start.sh`, `patch_settings.py`, `README.md`) إلى Hugging Face Space أو شغّله على حاسوبك.
2. ارفع ملفات المشروع إلى مستودع GitHub وانتظر `Actions > Build APK`.
3. نزّل الـ APK من **Releases** أو من Artifacts > Rafiq-APK.
4. في شاشة البداية الصق عنوان الخادم في حقل «عنوان خادم الفحص الدقيق».
