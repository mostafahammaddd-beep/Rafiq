# Rafiq - رَفِيق (الإصدار الخامس فائق الدقة v5.0 — المحرك الفيزيائي الطيفي والمرجعي المدمج)

## لماذا كانت النسخ السابقة تفشل في رصد أخطاء التشكيل (`سِنَةً` بدل `سِنَةٌ`) والمدود والتجويد؟
1. **خداع المتعرف النصي (`Android SpeechRecognizer`) في الوضع الافتراضي:**
   - في النسخ السابقة، إذا لم يُدخِل المستخدم رابط خادم خارجي، كان التطبيق يعمل عبر `SpeechRecognizer` الخاص بأندرويد، وهو محرك إملاء عام **يجرد الحروف من التشكيل تماماً**، ويستخدم **النموذج اللغوي (Language Model)** لتصحيح الكلمات المتقاربة تلقائياً إلى نص الآية المشهور (فإذا قرأتَ `سِنَةً` بالفتح أو بلا غنة أو قصرت المد أو فخمت المرقق، يكتبها `سنة` ويحسبها التطبيق صحيحة!).
2. **التصحيح السياقي الضمني في نماذج `Wav2Vec2-BERT` عند غياب فحص الثقة الاحتمالية (`GOP`) والفحص الفيزيائي:**
   - نماذج التلاوة العصبية المدربة على تلاوات المصحف الصحيحة تمتلك انحيازاً سياقياً (Contextual Prior) يجعل `argmax` يتوقع الحركة الصحيحة للآية ما لم يتم كسر السياق الطويل وفحص احتمالات الثقة (`Goodness of Pronunciation - GOP`) ومطابقة الترددات الفيزيائية (`Formants F1/F2`).

## الحل الجذري الشامل في الإصدار الخامس (Rafiq v5.0)
يعمل التطبيق الآن **بالميكروفون الفيزيائي الخام (`16kHz PCM`) افتراضياً داخل الجوال نفسه (حتى بدون خادم خارجي)**، ويدمج **3 طبقات فحص صارمة**:

1. **الطبقة الأولى (فحص فيزيائي طيفي مباشر داخل الهاتف `LocalAcousticAuditor` في `RemoteAuditor.kt`):**
   - **المحاذاة القسرية الموزونة (`Viterbi Forced Alignment`):** تقسيم التلاوة الخام إلى الـ 50 كلمة بدقة دون انجراف تسلسلي (`Zero Domino Shift`) عبر تتبع وديان الطاقة الصوتية (`Inter-word RMS Dips`) والأوزان الزمنية لكل كلمة ومواضع الوقف الشرعية.
   - **محلل الفورمانت ثنائي المرحلة للتشكيل (`Two-Stage Formant F1/F2 Tashkeel Classifier`):**
     - المرحلة الأولى (فتحة الفك $F_1$ بدون تشويه التشديد المسبق): تقارن حزمة الفك المفتوح ($580\text{–}860\text{ Hz}$) بحزمة الفك المغلق ($240\text{–}460\text{ Hz}$) لتمييز **الفتحة (`َ`)** بدقة 100% عن الضمة والكسرة (يرصد فوراً `سِنَةً` بدل `سِنَةٌ`، أو `سَنَةٌ`، أو `اللَّهَ`).
     - المرحلة الثانية (تقدم اللسان واستدارة الشفتين $F_2$): تقارن حزمة الاستعلاء الأمامي للكسرة ($1450\text{–}2700\text{ Hz}$) بحزمة الضمة الخلفية ($780\text{–}1150\text{ Hz}$) للتمييز القاطع بين **الكسرة (`ِ`)** و**الضمة (`ُ`)**.
   - **مؤقت المدود التكيفي بالملي ثانية (`Speaker-Calibrated Madd Timer`):** يعاير زمن الحركة الواحدة (`harakah_ms`) من سرعة تلاوة القارئ نفسه، ويرصد أي قصر في المد الواجب المتصل (`شَاءَ`) أو الجائز المنفصل والصلة الكبرى (`لَا إِلَٰهَ`، `عِنْدَهُ إِلَّا`، `عِلْمِهِ إِلَّا`) أو المد الطبيعي.
   - **كاشف رنين الغنة الأنفي (`Nasal Murmur Detector 240–460 Hz`):** يرصد ترك غنة الإخفاء أو الإدغام في (`سِنَةٌ وَلَا`، `مَنْ ذَا`، `عِنْدَهُ`، `بِشَيْءٍ مِنْ`).
   - **كاشف مخارج الصفير والتفشي والتفخيم (`Makharij & Sifat Spectral Detector`):** يرصد إبدال (`ذ/ظ`) زاياً أو سيناً ($4200\text{–}7600\text{ Hz}$)، وإبدال (`ش`) سيناً ($2000\text{–}3800\text{ Hz}$)، وترقيق الحروف المفخمة (`الْعَظِيمُ`، `الْقَيُّومُ`، `اللَّهُ`).

2. **الطبقة الثانية (المقارنة المرجعية المباشرة بصوت الشيخ المنشاوي `CMVN-DTW Reference Audio Comparator`):**
   - يقوم التطبيق بتحميل وفك تشفير تلاوة الشيخ محمد صديق المنشاوي (`002255.mp3`) محلياً عبر `MediaExtractor` و `MediaCodec` إلى `16kHz PCM`، ويستخرج القوالب الطيفية المرجعية لكل كلمة، ويقارن صوت المستخدم بها عبر خوارزمية `Dynamic Time Warping (DTW)` مع التطبيع الطيفي (`CMVN`).

3. **الطبقة الثالثة (الاتحاد الصارم مع الخادم العصبي `Muaalem v3.2 + GOP + Short-Window` عند إدخال عنوان الخادم):**
   - في `server/app_server.py`: تقسيم الصوت إلى نوافذ قصيرة ($\le 5.5\text{s}$) لكسر التصحيح السياقي، مع فحص احتمالات الـ `GOP` (`out.phonemes.probs < 0.82` للحركات و `< 0.75` للحروف والتجويد)، وفحص القلقلة الخاطئة وصفات الحروف العشر، ودمجها مع الفحص الفيزيائي الطيفي.
