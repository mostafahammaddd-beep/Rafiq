# خادم الفحص الدقيق لتطبيق «رَفِيق» (النسخة المطوّرة v4)

يشغّل نموذج **quran-muaalem** مع محرك محاذاة «رَفِيق» المتقدم (`app_server.py`) الذي يعالج جذور أخطاء التسميع:
1. **تقسيم صوتي ذكي عند الوقفات (Waqf Segmentation):** يقسم التلاوة الطويلة عند وقفات التنفس الطبيعية (≥ 320ms) ليعمل نموذج `Wav2Vec2-BERT` في نطاقه المثالي دون تشتت الانتباه في المقاطع الطويلة.
2. **محاذاة مترابطة للوقف والوصل والابتداء (Coupled Waqf/Wasl/Ibtida DP):** لا تُلوَّن الكلمات الموقوف عليها وقفاً صحيحاً (مثل `الْقَيُّومُ`، `نَوْمٌ`، `الْأَرْضِ`، `بِإِذْنِهِ`، `شَاءَ`، `وَالْأَرْضَ`) بالأحمر خطأً بسبب تسكين أواخرها أو المد العارض للسكون أو حذف صلة الضمير الصغرى وقفاً أو الابتداء بهمزة الوصل بعدها.
3. **كشف صارم لأخطاء الحروف والتشكيل والتجويد (100%):** يرصد أي إبدال في الحرف أو المخرج، وأي تغيير في الحركة (فتحة/ضمة/كسرة)، وأي إخلال بأحكام التجويد (المدود، الإخفاء، الإدغام، القلقلة، والصلة).
4. **فحص صفات الحروف العشر (`sifat`):** يفحص التفخيم والترقيق (مثل لام لفظ الجلالة وحروف الاستعلاء والاستفال)، والإطباق والانفتاح في (`ص، ض، ط، ظ`).
5. **منع تسرب الأخطاء عبر المسافات:** يُنسب كل خطأ إلى الكلمة صاحبة الخطأ وحدها دون تلوين الكلمة المجاورة لها.

## التشغيل

### أ) Hugging Face Space (مجاني)
1. أنشئ Space جديداً واختر SDK = **Docker**.
2. ارفع كل ملفات هذا المجلد إلى جذر الـ Space: `Dockerfile` و `app_server.py` و `start.sh` و `patch_settings.py` و `README.md`.
3. انتظر البناء، ثم أول إقلاع (تنزيل النموذج ≈ 2.4GB).
4. الصق العنوان `https://<حسابك>-<اسم-الـSpace>.hf.space` في حقل «عنوان خادم الفحص الدقيق» داخل التطبيق.

### ب) حاسوبك (أسرع، خصوصاً مع GPU)
```bash
docker build -t rafiq-server .
docker run -p 8001:8001 rafiq-server
```
العنوان في التطبيق: `http://<عنوان-IP-الحاسوب>:8001` (الجوال والحاسوب على نفس الشبكة).

## اختبار الخادم بدون التطبيق
```bash
curl -X POST http://localhost:8001/correct-recitation \
  -F error_ratio=0.2 -F sura_idx=2 -F aya_idx=255 -F lenient_madd=true -F "file=@rec.wav"
```
يعود JSON يتضمن `words_audit` (تفصيل دقيق لكل كلمة من الـ 50 كلمة) و `errors` و `predicted_phonemes`.
