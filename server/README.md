# خادم الفحص الدقيق لتطبيق «رَفِيق» (الإصدار الخامس الهجين v5.0)

يجمع الخادم في الإصدار الخامس (`app_server.py`) بين الذكاء الاصطناعي العصبي (`obadx/muaalem-model-v3_2`) والفحص الفيزيائي الطيفي (`Formants F1/F2 & Madd & Ghunnah`) وفحص الثقة الاحتمالية (`GOP`):

1. **كسر التصحيح السياقي عبر النوافذ القصيرة (`Short-Window Context-Breaking ≤ 5.5s`):** يقسم التلاوة عند وقفات التنفس وعند وديان الطاقة الصوتية لمنع محول `Wav2Vec2-BERT` من تصحيح أخطاء التشكيل بالاعتماد على سياق الآية.
2. **فحص احتمالات الثقة في النطق (`Goodness of Pronunciation - GOP`):** يفحص `out.phonemes.probs` لكل حركة (`< 0.82`) ولكل حرف وحكم تجويد (`< 0.75`) لكشف أي تردد أو إبدال في الحركة حتى لو حاول النموذج تقريبها.
3. **الفحص الفيزيائي الطيفي المدمج (`Two-Stage Formant F1/F2 + Madd Timer + Ghunnah + Makharij`):** يفحص ترددات الفورمانت للفتحة والضمة والكسرة، وزمن المدود بالملي ثانية، ورنين الغنة الأنفي، ومخارج الصفير والتفشي والتفخيم.
4. **محاذاة مترابطة للوقف والوصل والابتداء (`Coupled Waqf/Wasl/Ibtida DP`) وفحص صفات الحروف العشر (`sifat`) والقلقلة.**

## التشغيل

### أ) Hugging Face Space (مجاني)
1. أنشئ Space جديداً واختر SDK = **Docker**.
2. ارفع كل ملفات هذا المجلد إلى جذر الـ Space: `Dockerfile` و `app_server.py` و `start.sh` و `patch_settings.py` و `README.md`.
3. انتظر البناء، ثم أول إقلاع (تنزيل النموذج ≈ 2.4GB).
4. الصق العنوان `https://<حسابك>-<اسم-الـSpace>.hf.space` في حقل «عنوان خادم الفحص الدقيق» داخل التطبيق.

### ب) حاسوبك (أسرع، خصوصاً مع GPU)
```bash
docker build -t rafiq-server .
docker run -p 8001:8001 rafiq-server
```
العنوان في التطبيق: `http://<عنوان-IP-الحاسوب>:8001` (الجوال والحاسوب على نفس الشبكة).
